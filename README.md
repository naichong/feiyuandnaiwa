# 大肥鱼和奶蛙 (feiyuandnaiwa)

一个用 Android Studio 开发的安卓桌面宠物小项目，主角是「大肥鱼」和「奶蛙」两只小可爱。

作者：奶虫

## 项目简介

大肥鱼和奶蛙会以悬浮窗的形式常驻在手机桌面上，陪你一起用手机。
它们可以被拖动、点击互动，也会自己做一些小动作，比如吐泡泡、蹦跳、眨眼和傻笑。

> 目前是个人练习项目，功能会慢慢补充，代码和素材都在仓库里。

## 角色介绍

| 角色 | 形象 | 性格 | 拿手动作 |
|------|------|------|----------|
| 大肥鱼 | 圆滚滚的胖鱼 | 慵懒、爱吃 | 缓慢游动、吐泡泡 |
| 奶蛙 | 奶白色小蛙 | 活泼、爱笑 | 原地蹦跳、眨眼、大笑 |

## 已实现 / 计划功能

- [x] 桌面悬浮显示，不影响正常使用手机
- [x] 手指拖拽移动位置
- [x] 单击触发随机动作
- [ ] 双击让大肥鱼和奶蛙互动
- [ ] 长按打开功能菜单（切换角色、隐藏、退出）
- [ ] 低功耗帧动画循环

## 技术说明

- 开发工具：**Android Studio**
- 语言：Java / Kotlin
- 悬浮窗：`Service` + `WindowManager`，窗口类型为 `TYPE_APPLICATION_OVERLAY`
- 权限：需要申请 `SYSTEM_ALERT_WINDOW`（显示在其他应用上层）
- 动画：用 `SurfaceView` 或自定义 `View` 播放序列帧
- 交互：`OnTouchListener` 处理拖拽，`GestureDetector` 识别单击、双击、长按
